# 1 Getting Started

## History of C++

### Origins (1979–1985)
C++ was created by Bjarne Stroustrup at Bell Labs, starting in 1979. He originally called it "C with Classes," building on the C language by adding object-oriented features inspired by Simula (which he'd used during his PhD and admired for its program-structuring ideas, though he found it too slow for practical use).

### The name "C++" (1983)
In 1983, the language was renamed C++ — a pun on the ++ increment operator in C, signaling it as an "incremented" version of C.

### First Commercial Release (1985)
Stroustrup published The C++ Programming Language, and the first commercial implementation was released. Early C++ compilers (like Cfront) worked by translating C++ code into C, which was then compiled normally.

### Standardization Era

C++98: The first ISO standard, ratified in 1998, formalized the language after years of ad-hoc growth. It introduced templates, exceptions, namespaces, and the STL (Standard Template Library).
C++03: A minor bug-fix update to C++98.
C++11: A massive overhaul (nicknamed "C++0x" during development since it slipped past 2010). Added auto, lambda expressions, smart pointers, move semantics, the nullptr keyword, range-based for loops, and much more. Widely seen as a turning point that modernized the language.
C++14: A smaller refinement update to C++11.
C++17: Added structured bindings, if constexpr, filesystem library, and parallel algorithms.
C++20: Another major release — concepts, coroutines, modules, and ranges.
C++23: Continued refinement with std::expected, deducing this, and more standard library improvements.
C++26: Currently in development, expected to bring reflection, contracts, and further modernization.

### Philosophy
Throughout its history, C++ has stuck to a few guiding principles: "pay only for what you use" (zero-overhead abstractions), backward compatibility with C, and giving programmers low-level control alongside high-level abstraction — which is part of why it's remained dominant in systems programming, game engines, embedded systems, and performance-critical software for over four decades.
